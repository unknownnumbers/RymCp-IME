# PC配置與使用範圍

本倉庫先提供源碼與共享配置，沒有獨立安裝包。首次整理的公開快照需要隔離測試，不應直接覆蓋既有使用者資料夾。

## 必需的前端與引擎

`config/pc`是使用者資料層，仍需官方共用的`default`、`pinyin`、`symbols`、`key_bindings`、`grammar`、`stroke`及OpenCC資源。原生基底與固定版本見[構建說明](BUILD.md)。

本工程使用可寫候選頁長、詞碼跨度、預編輯與學習相關的自訂介面，需配套Weasel／librime／librime-lua修改。保留的原生來源分為61033 TSF／服務、61020 IME及step-only＋N01引擎，不應把全部元件稱為同一版本。

公開配置含一般詞庫及索引；這些資料不是個人學習庫。現有個人學習不隨本倉庫移轉，也不作公開構建輸入。

## 先在隔離目錄檢查

1. 依構建文件準備固定來源及配套引擎，不執行安裝器或改註冊。
2. 使用全新目錄作測試用使用者資料夾，將`config/pc`來源放入其中，另提供所需官方共用資料。
3. 依日語說明重生／核對獨立假名表，確認主方案、日語方案及各helper字典可部署。
4. 用空庫核對候選、選詞餘碼、模式切換及工具；完整桌面輸入驗收另行記錄。公開CI的源碼／資料檢查不等於已覆蓋所有應用。

OpenCC轉換所需資源的可攜設定見配置內附工具及來源說明。不要把個人安裝絕對路徑寫入共享配置。

## 主要入口

| 入口 | 用途 |
| --- | --- |
| 中文主方案 | 拼音、簡拼、容錯及英文／混合詞候選 |
| 左Shift | 主方案中文與智能英文切換 |
| 右Shift | 原生ASCII模式切換，沿用目前草稿規則 |
| Ctrl+E／Ctrl+R | 日語／中文方案入口，具體以配置與實際草稿狀態為準 |
| Ctrl+Shift+F | TC／SC輸出切換；不代表Windows介面或註冊語言切換 |
| `uU` | 筆畫／拆字查字，候選讀音與資訊輸出 |
| `U` | Unicode工具 |
| `cC` | 計算器 |

日語的大小寫、假名、小假名、`q/qQ`、`xX`、`v/vV`及資訊顯示見[日語說明](../config/pc/JAPANESE.md)。工具和查詢的控制前綴是程式介面，不能把它們當作鄉音拼寫標準。

## 目前界線

- 假名、漢字及q／x／v以本工程規則為準；早期借鑒來源在README列出，不以兼容其原碼表為驗收目標。
- 小型字形修正是明列的工程選擇，不表示收錄或再分發原MDX整庫，也不提供吳語音訊或IPA。
- 現有普通話讀音及TC／SC轉換屬底座功能；鄉音提示、鄉音拼寫輸入、發音參考仍見[待辦](../TODO.md)。
