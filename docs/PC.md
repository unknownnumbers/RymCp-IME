# 墨芯完整方案

從墨芯整合安裝器安裝前端與通用方案. 源碼位於 `config/pc`, 採新裝範例設定, 請先備份已有同名檔案.

中文預設 SC 輸出, 可切換 TC/SC. 中文橫排 5 項, 智能英文直排 6 項, 日語直排, 均使用非內嵌組字.

中文支援現有全拼、縮寫、容錯、組句與本地學習. 組字中的 `"` 將左側區塊約束為完整音節; `'` 保持音節分隔用途, Tab 保持導航. 原碼 Return 保留輸入標記, 正常選詞只提交候選文字.

智能英文支援完整詞、補全、容錯、大小寫與既有縮寫展開. 平假名、片假名、漢字、romaji 與 q/x/v 查詢見 [日語說明](../config/pc/JAPANESE.md). 查字與工具來源見 [來源索引](sources/README.md).

## 可選詞彙

通用方案可直接使用. 將需要的 DLC 模組資料夾複製到用戶資料夾的 `rymcp_dlc/` 下, 再重新部署. 可用模組為 `math`、`physics`、`computer` 及 `poetry`. 來源與生成方式見 [DLC 來源](dlc-sources.md).

## 更新與合併

保留用戶學習庫. 已有 `default.custom.yaml`、`weasel.custom.yaml`、`rime.lua` 或同名方案自訂時, 先備份並對照新範例合併. 同名自訂可能覆蓋新預設, 重新部署後核對方案清單、Lua 入口與候選布局.
