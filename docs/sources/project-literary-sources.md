# 兩句詩的小表

詞表只補林則徐《赴戍登程口占示家人》二首其二的兩句：

| 詞句 | 規範拼音 | 初始權重 |
| --- | --- | ---: |
| 力微任重久神疲 | `li wei ren zhong jiu shen pi` | 100 |
| 再竭衰庸定不支 | `zai jie shuai yong ding bu zhi` | 100 |

詩句來源核對為[人民日報海外版2016-04-07賞析](https://paper.people.com.cn/rmrbhwb/html/2016-04/07/content_1668213.htm)；力微任重讀音另核對[教育雲詞條](https://pedia.cloud.edu.tw/Entry/Detail?title=力微任重)。本表沒有複製現代賞析或釋義文字。

詞碼及權重由本工程整理，仍使用`luna_pinyin`學習，不設詩句專用別名／硬置頂。只補這兩句，不宣稱整首已收或把結果當作模型自由組句的證據。
