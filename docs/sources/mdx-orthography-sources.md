# 小型字形修正規則的來源與範圍

現有`lua/cn_orthography.lua`與`opencc/mdx_words.txt`是本工程明列的小型字形選擇規則. 規則制定時參考使用者本地整理的吳語MDX詞典; 公開內容不包含該MDX檔案、整庫、釋義全文、sense索引或研究抽取材料. 這份說明也不宣告外部MDX資料庫已取得GPL再分發授權.

單字規則以標準國語code限定字形選擇, 處理乾、剋、吒、夥、徵、於、昇、氾、甦、甯、祕、脩、苧、蒐、釐、陞、麽及麼/噁的特定路徑; 不建立字典詞條或新學習身份. `噁 e`、`蘋 pin/ping`等原生多值路徑保持. Unihan17.0.0只作讀音佐證, 不因字形相近就任意抄讀音.

詞形檔只有四條明列映射:

| 輸入詞形 | 規則輸出 |
| --- | --- |
| 洪昇 | 洪昇 |
| 束脩 | 束脩 |
| 二噁英 | 二𫫇英 |
| 白蘋洲 | 白𬞟洲 |

這些是特定詞義/詞形的局部選擇, 不是無條件單字等價, 也不是整份吳語字典. 程式及配置的本工程表達沿GPLv3; 外部詞典本體的版權/授權不由本工程更改. OpenCC通用轉換仍依[Apache-2.0](../../licenses/OpenCC-LICENSE.txt), 相應資源由標準OpenCC資料提供.
