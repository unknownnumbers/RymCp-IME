# English case evidence

The generated form table resolves existing core/canonical-extension collisions. It does not provide an independent frequency corpus.

Evidence comes from the complete [SCOWL 2020.12.07 release](https://sourceforge.net/projects/wordlist/files/SCOWL/2020.12.07/scowl-2020.12.07.tar.gz/download), with exact original-case membership in cumulative English, American and British word lists through size 80. The original archive is fixed by `sources/base/source-manifest.json`.

The generator registers positive lowercase evidence beside the existing canonical form. Absence means unconfirmed evidence. Mixed-case completion continues to follow actual canonical spellings.
