# Sources and reconstruction scope

The source release contains two profiles, generators, fixed public inputs and original component notices. Each distributed file is covered by `licenses/file-licenses.json`; `release-manifest.json` records the source snapshot.

- [Base dictionaries and frequency data](base-dictionaries.md).
- [Optional vocabulary modules](../dlc-sources.md).
- [English core](english-core-sources.md), [forms and aliases](english-extensions-sources.md), [case evidence](english-case-forms-sources.md).
- [Compact model](luna-compact-model-sources.md).
- [Shared configuration](shared-config-sources.md), [radical and stroke data](radical-stroke-sources.md), [lookup readings](u-readings-sources.md).
- [Japanese q data](jp-q-sources.md), [Japanese v data](jp-v-sources.md), [tools](tools-sources.md), [mixed phrases](mixed-phrases-sources.md).
- [Output orthography](mdx-orthography-sources.md), [official Weasel profile](official-weasel-sources.md), [native components](native-components.md).

Fixed snapshots and deterministic conversions establish the supplied build inputs. They do not establish that every historical upstream corpus, tokenizer and filtering pipeline can be reconstructed. Original source notices retain their own terms.
