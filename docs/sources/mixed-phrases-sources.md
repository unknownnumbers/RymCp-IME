# 五條精選混合詞

本表只收：`U 盤`、`A4 紙`、`3D 打印`、`Windows 版`、`Wi-Fi 密碼`，沒有將上游整份混合詞庫匯入。

來源為Ice固定`da1fbe602e38f26db846fa10120ee64c2b0324c0`的[原詞](https://github.com/iDvel/rime-ice/blob/da1fbe602e38f26db846fa10120ee64c2b0324c0/others/cn_en.txt)及[輸入碼](https://github.com/iDvel/rime-ice/blob/da1fbe602e38f26db846fa10120ee64c2b0324c0/en_dicts/cn_en.txt)，[GPLv3全文](../../licenses/english-extensions-Ice-GPL-3.0.txt)隨附。

本工程在Latin／漢字邊界用一個空格，整理TC規範詞形供既有輸出轉換使用，保留中文音節邊界及逐音節連續前綴匹配。五個規範code為`upan`、`asizhi`、`sanddayin`、`windowsban`、`wifimima`。

公開資料不含任何使用者選擇記錄；實際學習仍由使用者自己的`pc_mixed`資料庫保存。
