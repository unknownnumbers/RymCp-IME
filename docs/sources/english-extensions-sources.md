# English forms and aliases

Source: [iDvel/rime-ice extension dictionary](https://github.com/iDvel/rime-ice/blob/da1fbe602e38f26db846fa10120ee64c2b0324c0/en_dicts/en_ext.dict.yaml), fixed commit `da1fbe602e38f26db846fa10120ee64c2b0324c0`. The original source is committed in `sources/base/english-extensions.dict.yaml`.

The general spelling algebra derives readable aliases for source digits and symbols. Entries share native word identities when they refer to a core vocabulary word. Case-preserving canonical labels and expansion forms retain their source weights. The complete source is processed by the same rules.

Generation: `scripts/data/rebuild_base.py`. Recall-index generation: `scripts/data/build_english_index.py`. Both profiles consume the same generated base data.

The original [Ice GPL-3.0 notice](../../licenses/english-extensions-Ice-GPL-3.0.txt) is retained. Upstream notices and data attribution remain distinct from this repository's original generator code.
