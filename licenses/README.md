# 授權正文與署名

整體範圍見[第三方通知](../THIRD_PARTY_NOTICES.md), 各檔與各部分的授權見[逐檔索引](file-licenses.json), 來源及修改見[公開來源索引](../docs/sources/README.md).

- 根`LICENSE`保存GPLv3正文. 本工程原創程式碼、配置、生成器、測試及原生修改採GPL-3.0-only.
- 本目錄保留日用來源所附的原授權/署名正文; 同版GPL/LGPL的多個檔名保留, 是為了對應各元件原通知, 沒有產生不同的新授權.
- `CC-BY-SA-4.0.txt`供本工程各說明文件的原創文字及EDRDG衍生資料引用. 原創說明涵蓋README、使用與構建說明、來源整理及設計文件; EDRDG資料保留其原署名與來源範圍.
- `english-core/`保存SymSpell、Google Books與SCOWL的8份完整來源/授權通知.
- `radical-stroke/`保存Mirtle與rime-stroke的原授權、credits及AUTHORS.
- `supplement/`保存額外補齊的上游通知, 來源URL、固定commit及SHA256見[manifest](third-party-source-manifest.json).

第三方原文、授權通知、來源引文及程式片段依各自條款保存. 生成資料保留所用來源的授權與署名.
