# 授權正文與署名

整體範圍見[第三方通知](../THIRD_PARTY_NOTICES.md), 來源及修改見[公開來源索引](../docs/sources/README.md).

- 根`LICENSE`保存本工程主程式碼的GPLv3正文.
- 本目錄保留日用來源所附的原授權/署名正文; 同版GPL/LGPL的多個檔名保留, 是為了對應各元件原通知, 沒有產生不同的新授權.
- `CC-BY-SA-4.0.txt`同時供新寫的README/TODO/PC/BUILD說明 (包括原生構建、日語PC與OpenCC設定說明) 與EDRDG衍生資料引用; 兩者的版權來源與範圍分開, 程式腳本不因屬於構建流程而改用CC.
- `english-core/`保存SymSpell、Google Books與SCOWL的8份完整來源/授權通知.
- `radical-stroke/`保存Mirtle與rime-stroke的原授權、credits及AUTHORS.
- `supplement/`保存額外補齊的上游通知, 來源URL、固定commit及SHA256見[manifest](third-party-source-manifest.json).

授權原文及第三方通知保持原文, 不能將這些檔案的存在理解為全部資料都轉為根GPLv3或專案文檔CC BY-SA4.0.
