# RymCp IME

**Recall Your Mother-Tongue Chinese Pronunciation IME**  
**鄉音復健輸入法 | 乡音复健输入法**

RymCp希望把日常打字變成重新熟悉鄉音的入口。現在先公開可共享的Rime PC底座：配置、Lua、必要資料、原生修改源碼及構建入口，之後逐步接入復健功能。

## 現有Rime底座

本倉庫目前是Windows PC的源碼與配置快照，尚未提供獨立安裝包。

| 範圍 | 已有內容 |
| --- | --- |
| 中文輸入 | 拼音、簡拼、容錯候選、選詞餘碼及原生學習整合 |
| 英文輸入 | 智能英文、補全與糾錯、大小寫處理、固定混合詞及學習整合 |
| 字形與候選介面 | TC／SC輸出切換、少量明列詞形修正、中文與英文候選布局；Windows註冊語言另外設定 |
| 日語輸入 | 獨立重寫的羅馬字／假名基底；平假名、片假名，以及q／x／v查詢模式，使用有來源記錄的日語詞庫 |
| 查字與工具 | 拆字／筆畫查字、普通話讀音顯示、Unicode、Greek／數學符號及計算器 |
| 原生修改 | Weasel前端、librime及librime-lua的固定上游與完整補丁 |

早期日語輸入設計借鑑了[Selaube的日語方案](https://github.com/Selaube/rime-jp_sela)。目前假名、漢字與q／x／v規則以RymCp自身需求及實作為準，不以兼容原方案為目標。

日語基底按本工程規則生成，沒有包含Sela原方案或原字典全文。部分檔名及schema ID仍是目前模組使用的`jp_sela`識別碼，並非對原方案的依賴。具體規則見[日語用法](config/pc/JAPANESE.md)。

這份配置依賴自訂前端／引擎介面。直接匯入任意版本Rime不代表已驗證可用；請先讀[PC配置說明](docs/PC.md)及[構建說明](docs/BUILD.md)。本倉庫不包含個人學習庫、備份、現場日誌或聊天記錄。

## 鄉音復健的理念

有人已熟練使用國語、漢語拼音、注音或五筆，卻不再記得家鄉話怎麼讀。本專案希望整理各地方話的拼寫規則、IPA與字詞讀音，讓使用者：

1. 先用自己熟悉的方式打字，同時看到所選鄉音的拼寫與IPA。
2. 在日常輸入中反覆接觸字詞及讀音對照，逐漸熟悉鄉音。
3. 熟悉後切換模式，嘗試直接以鄉音拼寫輸入。
4. 後續加入單字、詞語的發音參考及正音支援，再研究連讀中的音變。

首要目標是讀寫上的復健。粵語、吳語、西南官話、徽語、江淮官話等是考慮方向，會按具體地點、變體及資料逐項整理；首個變體與接入順序未定。

**鄉音拼寫／IPA提示、鄉音拼寫輸入與發音參考仍是待接入功能。** 現有普通話讀音、拼音容錯及日語查詢不代表鄉音復健流程已完成。提示放在哪裡、是否隨字上屏、怎樣切換及處理多音字，會在實作時逐項確定；注音、五筆等也不是目前已完成鄉音提示的入口。

## 待辦與發布順序

- [ ] 完善PC底座的公開構建、隔離驗證、使用說明及第三方通知。
- [ ] 在源碼與配置穩定後，整理獨立安裝包。
- [ ] 選定首個具體地方變體，整理有明確來源的拼寫、IPA及字詞讀音。
- [ ] 接入熟悉輸入方式下的鄉音提示，以及鄉音拼寫輸入模式。
- [ ] 補充字詞發音與正音參考，整理音源品質及授權。
- [ ] 研究連續變調、聲母弱化及連讀習慣。
- [ ] 逐步整理Android及其他地方話。
